# crimsonwolf.llc

Website for Crimson Wolf LLC, hosted on Netlify.

- `index.html`: home page (apps, about, contact)
- `privacy.html`: privacy policy (website and app), served at `/privacy`
- `terms.html`: app terms of use, served at `/terms`

No build step. Netlify publishes this folder as-is on every push to `main` (see `netlify.toml`).
